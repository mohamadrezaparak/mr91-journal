# MR91 Journal 1.3.1-beta — راهنمای ساخت APK

## نکته مهم درباره خطای قبلی
در ZIP قبلی کل پروژه داخل پوشه‌ی `MR91-Journal-1.3.0/` قرار داشت. اگر فقط محتویات ZIP را در یک پوشه‌ی دیگر آپلود کرده باشید، Gradle در ریشه‌ی مخزن پروژه‌ی اندروید را پیدا نمی‌کند و خطای `Task 'assembleDebug' not found` می‌دهد. این نسخه اصلاح شده و فایل‌های پروژه مستقیماً در ریشه‌ی ZIP هستند.

## روش آپلود صحیح
1. این ZIP را روی کامپیوتر Extract کنید.
2. وارد پوشه‌ی استخراج‌شده شوید؛ باید همان‌جا `settings.gradle`، `build.gradle` و پوشه‌ی `app` را ببینید.
3. تمام محتویات همین پوشه (از جمله پوشه‌ی مخفی `.github`) را در ریشه‌ی مخزن `mohamadrezaparak/mr91-journal` آپلود کنید و فایل‌های قبلی را در صورت درخواست Replace کنید.
4. در GitHub به Actions بروید و Workflow با نام `MR91 Journal - Build APK` را باز کنید. `Run workflow` را بزنید.
5. پس از سبز شدن اجرا، در صفحه‌ی خلاصه‌ی همان اجرا، بخش Artifacts را باز کنید و `MR91-Journal-1.3.1-debug-apk` را دانلود کنید.
6. ZIP دانلودشده را Extract کنید؛ فایل `app-debug.apk` داخل آن است.
